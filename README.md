# Trees

Four Python examples of binary trees and binary search trees.

- [binary_tree.py](binary_tree.py): Creates a root with two children and prints their values.
- [height_of_binary_tree.py](height_of_binary_tree.py): Counts the levels along the longest path. An empty tree has height 0 and a single node has height 1.
- [size_of_binary_tree.py](size_of_binary_tree.py): Recursively counts all nodes in a tree.
- [search_bst.py](search_bst.py): Searches for 60 in a binary search tree, printing each node checked.

Each file runs independently and prints its example results.
